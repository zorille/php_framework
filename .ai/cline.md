# Cline

- Avant modification, inspecter `config.php`, le module concerne et les classes parentes.
- Lister les fichiers a modifier avant d'ecrire.
- Apres modification, executer `php -l` sur les fichiers touches si possible.
- Ne pas lancer d'appels reseau/API externes sans accord explicite.
- Respecter les retours par reference et les signatures existantes.
