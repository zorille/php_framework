# Regles IA pour php_framework

Ces regles s'appliquent aux assistants IA travaillant sur ce depot. Elles sont derivees du code et de la documentation locale dans `docs/`.

## Regle principale

Ne pas inventer de fonctionnalite, d'API, de test ou de convention. Lire le code avant de modifier. Respecter les patterns historiques du depot.

## Fichiers de regles

- `shared-rules.md`: regles communes a tous les assistants.
- `continue.md`: consignes pour Continue.
- `cline.md`: consignes pour Cline.
- `cursor.md`: consignes pour Cursor.
- `claude-code.md`: consignes pour Claude Code.
- `copilot.md`: consignes pour GitHub Copilot.
- `codex.md`: consignes pour Codex.
